# QR Studio — QR Code Generator & Designer

**[🚀 Live Demo](https://joshika221b-source.github.io/QR-generator/)**

Plain HTML, CSS and JavaScript. No install, no server.

## Run

Open `index.html` in any modern browser. Keep all files in the same folder.

## Files

* `index.html` — page structure
* `style.css` — design, dark mode, responsive layout
* `script.js` — QR generation, validation, presets, download/copy, recent codes, theme
* `qrcode.js` — open-source QR encoder (qrcode-generator by Kazuhiko Arase, MIT license)

## Features

* URL / Text / Email / Phone / Wi-Fi QR codes
* Live QR preview
* Custom size and colors
* Error correction and padding controls
* Presets — Classic, Ocean, Purple, Dark
* Input validation
* Low-contrast warning
* PNG download
* Copy to clipboard with fallback
* Recent codes — up to 6 saved using `localStorage`
* Dark / light mode
